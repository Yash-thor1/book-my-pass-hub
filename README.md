# Book My Play Hub 🎭

An online event and play booking platform built using React and TypeScript.

## 🚀 Features
- Browse available plays/events
- Book tickets
- Responsive UI
- Modern design using Tailwind CSS

## 🛠️ Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
